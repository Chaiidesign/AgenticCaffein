# Working agreement

Read README, LOOP.md, and docs/BACKEND-PRD.md before editing. This is a general business workspace; café data is a fixture, not the architecture.

- One bounded goal per loop. Define checks before implementation; record results and stop state.
- Never describe simulated approvals, quotes, outcomes, channels, or agents as live integrations.
- Keep arithmetic and authority in deterministic code. Presentation cannot grant new permission.
- Preserve proposal, intent, and snapshot versions; invalidate approval after consequential changes.
- Filter audience context server-side before a production model or channel receives it.
- Preserve stable component IDs, user input, focus, and decision orientation when adapting surfaces.
- No supplier contact, spending, invitations, or channel messages without explicit scope and confirmed recipients.
- No autonomous constitutional changes to business intent, benchmark definitions, design tokens, or authority.
- Use `npm test` and `npm run check`; add meaningful checks for changed lifecycle or authority rules.
- Keep secrets out of source, browser bundles, logs, and committed files.
- No agent graph unless actual dependencies or parallel work earn it. Implement bounded loops first.
